## Color treatment

- Main neon colors: `#00D9F5`, `#00EDFF`.
- Highlights: `#82F7FF`.
- Shaded blue planes: `#008BBA`.
- Black stage: `#03070D`.
- Dark block faces: `#11161E`, with a thin shaded-blue edge so they remain visible.
- Wordmark: Product in `#82F7FF`; IVF in `#00EDFF`.

The subtle 0.8-unit glow preserves the small gaps between V1's blocks. Dark presentation backgrounds are editable rectangles named `productivf-v3-background`. The full logos retain V1's live ProductIVF lettering and original font fallback stack.

Open `04-comparison.svg` or `04-comparison.png` for all three directions together. The standalone SVGs retain their V1 viewBoxes and layouts.

V1 and V2 remain unchanged. Only concept assets and this documentation are added; application code is untouched.
